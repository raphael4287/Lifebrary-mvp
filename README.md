# Lifebrary ─ 人生故事圖書館

**「讓每一段真實人生都被看見、被共鳴」** 的故事分享平台

![Demo Screenshot](demo-image-link.png)

### 專案亮點
- 完整的前端 MVP，已做出高品質 UI/UX
- 設計專屬的情緒互動系統（感動、共鳴、激勵等），取代傳統評分
- 完善的投稿流程 + 搜尋篩選 + 個人投稿管理
- 包含 AI 輔助審核與書籍化概念的產品思維

### 目前 Demo 完成功能
- 用戶系統（個人頁、投稿列表）
- 投稿系統（內建編輯器 + 檔案上傳模擬）
- 探索頁（搜尋、標籤、年份、性別篩選、排序）
- 閱讀頁 + 情緒互動功能
- 內容狀態管理（已發布 / 審查中 / 已驗證）
- 完整製作清單（Production Checklist）——詳細規劃後續 5 個階段開發

### 使用技術
- 前端：HTML5、CSS3、Vanilla JavaScript
- 設計風格：溫暖復古文藝風（Syne + Noto Sans TC）
- 資料模擬：LocalStorage + JSON

### 開發心得與反思
從這個專案我深刻體會到「產品思維」的重要性。不只是寫程式，更需要考慮使用者情感、內容審核機制、法律合規與成長循環。雖然目前仍是前端 Demo，但我已完整規劃了 MVP 到商業化的所有階段，未來希望能接上後端與 AI 功能。

### 未來發展方向
- 接入真實後端（Node.js / Firebase / Supabase）
- 實作 AI 預審與寫作輔助
- 書籍合成與 PDF 匯出
- 用戶信譽系統與推薦機制
