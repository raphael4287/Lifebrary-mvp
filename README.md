# Lifebrary ─ 人生故事圖書館

> **「讓每一段真實人生都被看見、被共鳴」** 的故事分享平台

![Lifebrary Hero](https://img.shields.io/badge/version-1.0.0--MVP-brightgreen) ![License](https://img.shields.io/badge/license-MIT-blue) ![Status](https://img.shields.io/badge/status-Active%20Development-orange)

## 📖 願景與使命

Lifebrary 始於一個簡單卻深刻的想法：**想要聽見家人的故事**。

從家庭的親密對話，到社區的鄰里故事，再到全世界每個角落的人生經歷——我們相信每個人的故事都值得被聽見、被理解、被共鳴。

**Lifebrary 的使命**是打造一個溫暖的故事分享生態，讓真實的人生故事成為連接人心的橋樑。不是虛構，不是表演，而是真實的、有溫度的、能夠觸動他人心靈的故事。

### 核心價值觀

- **真實性**：鼓勵分享真實的人生經歷，而非精心包裝的敘事
- **共鳴**：通過情緒互動系統，讓讀者與作者產生深層連結
- **多元性**：歡迎各種背景、年齡、文化的故事創作者
- **尊重**：建立安全、包容的社區環境，保護創作者隱私

##  核心功能

### 1. 故事探索系統
- **多維度搜尋**：按標題、作者、內容全文搜尋
- **智能篩選**：
  - 分類篩選（成長、家庭、冒險、夢想等）
  - 年份篩選（按故事發生年份）
  - 作者性別篩選
- **靈活排序**：最新優先、熱度優先、已驗證優先

### 2. 情緒互動系統
取代傳統的「點讚」或「評分」，Lifebrary 引入**情感共鳴機制**：

| 情緒反應 | 含義 | 使用場景 |
|---------|------|---------|
|  感動 | 故事觸動了我的心靈 | 溫暖、感人的故事 |
|  共鳴 | 我也有類似的經歷 | 共同經驗、相似處境 |
|  激勵 | 這個故事激勵了我 | 勵志、成長、突破 |

每個反應都會實時更新統計，幫助讀者了解故事的情感影響力。

### 3. 完整的投稿流程
- **富文本編輯器**：支持格式化文本、段落組織
- **元數據管理**：
  - 故事標題、分類、發生年份
  - 作者信息、性別（可選）
  - 自動時間戳記錄
- **草稿保存**：自動保存進度，避免數據丟失
- **內容狀態追蹤**：已發布 / 審查中 / 已驗證

### 4. 用戶個人中心
- **個人檔案**：展示用戶信息、個人簡介
- **故事管理**：
  - 查看所有投稿故事
  - 按狀態篩選（已發布、審查中、已驗證）
  - 編輯或刪除故事
- **統計儀表板**：
  - 總投稿數
  - 累計閱讀數
  - 獲得的情感共鳴數

### 5. 故事閱讀體驗
- **沉浸式閱讀**：清晰的排版、舒適的字體大小
- **作者信息卡**：快速了解故事創作者
- **相關故事推薦**：發現同分類的其他故事
- **社交分享**：分享故事到社群平台

## 🛠️ 技術架構

### 前端技術棧

```
React 19 + TypeScript
├── Wouter (輕量級路由)
├── Tailwind CSS 4 (樣式框架)
├── shadcn/ui (UI 元件庫)
├── Framer Motion (動畫)
└── Lucide React (圖標)
```

### 數據管理

**當前版本（MVP）**：使用 LocalStorage 進行客戶端數據持久化
- 故事數據：`lifebrary_stories`
- 用戶檔案：`lifebrary_user`
- 情緒反應：集成於故事數據中

```javascript
// 數據結構示例
{
  id: "story_1",
  title: "那個改變我人生的決定",
  author: "李明",
  category: "成長",
  content: "...",
  status: "verified",
  emotionStats: {
    moved: 234,
    resonance: 189,
    inspired: 312
  },
  viewCount: 1523,
  createdDate: "2024-05-10"
}
```

### 設計系統

**色彩方案**：溫暖復古文藝風
- 背景色：`#F5EFE7`（暖米色）
- 主文字：`#3D2817`（深棕色）
- 強調色：`#D4A574`（溫暖金色）
- 邊框色：`#E8DCC8`（淡米色）

**字體系統**
- 標題：Syne（現代、有力）
- 正文：Noto Sans TC（清晰、易讀）

**設計理念**
- 非對稱佈局，避免單調的中心對稱
- 手工感邊框和紋理背景
- 卡片懸停時的微妙陰影變化
- 情緒互動按鈕的動畫反饋

## 快速開始

### 環境要求

- Node.js 18+
- pnpm 10+

### 安裝與運行

```bash
# 1. 克隆項目
git clone <repository-url>
cd lifebrary

# 2. 安裝依賴
pnpm install

# 3. 啟動開發伺服器
pnpm dev

# 4. 打開瀏覽器
# 訪問 http://localhost:3000
```

### 構建生產版本

```bash
# 構建靜態資源
pnpm build

# 預覽生產構建
pnpm preview
```

##  使用指南

### 作為讀者

1. **探索故事**
   - 進入「探索」頁面
   - 使用搜尋框查找特定故事
   - 使用篩選器按分類、年份、作者性別篩選
   - 選擇排序方式（最新、熱度、已驗證）

2. **閱讀故事**
   - 點擊故事卡片進入閱讀頁面
   - 閱讀作者信息和故事內容
   - 使用情緒互動按鈕表達感受

3. **分享故事**
   - 點擊「分享」按鈕
   - 複製鏈接或分享到社群平台

### 作為創作者

1. **投稿故事**
   - 點擊「投稿新故事」按鈕
   - 填寫故事標題、分類、發生年份
   - 在編輯器中撰寫故事內容
   - 點擊「提交」發布故事

2. **管理故事**
   - 進入「我的故事」頁面
   - 查看所有投稿故事及其狀態
   - 編輯或刪除故事
   - 監看故事的閱讀數和情感反應

3. **更新檔案**
   - 進入「個人檔案」
   - 編輯個人信息和簡介
   - 查看累計統計數據

##  設計亮點

### 情緒互動系統的創新

傳統社交平台使用「讚」或「星級評分」，但這些機制無法準確表達對故事的複雜情感。Lifebrary 的情緒互動系統允許讀者同時表達多種情感：

- 一個故事可以**既感動又激勵人心**
- 讀者可以**撤回或改變**自己的反應
- 統計數據反映故事的**多維度影響力**

### 非對稱設計語言

避免常見的中心對稱佈局，採用：
- 不規則的卡片排列
- 錯落有致的內容分佈
- 手工感的邊框和陰影
- 溫暖的色彩搭配

這種設計風格傳達了「真實、有溫度、手工打造」的品牌氣質。

##  故事投稿指南

### 什麼樣的故事適合 Lifebrary？

 **歡迎投稿**
- 真實的人生經歷
- 個人成長和反思
- 家庭和人際關係故事
- 冒險和旅行見聞
- 職業和創業經歷
- 克服困難的故事

 **不適合投稿**
- 虛構小說或創意寫作
- 廣告或商業推廣
- 仇恨或歧視性內容
- 未經授權的他人隱私信息
- 違法或不當內容

### 投稿最佳實踐

1. **真實性優先**：分享你的真實感受和經歷
2. **尊重他人**：保護故事中涉及的其他人的隱私
3. **清晰表達**：組織好段落，使故事易於理解
4. **適當長度**：500-5000 字為佳（無硬性限制）
5. **分類準確**：選擇最符合故事主題的分類

##  已知問題與限制

### 當前版本限制

- LocalStorage 容量限制（通常 5-10MB）
- 單設備數據隔離（無跨設備同步）
- 無用戶認證機制
- 無實時協作功能

### 計劃改進

這些限制將在後續版本中逐步解決，特別是在後端整合後。
